# 📈 Fundamental Quant Framework (`fqf`)

> **量化基本面投研框架**：集宏观/行业监测、个股标准化分析、策略构建与自动化回测于一体的深度投研基座。

---

## 🎯 项目愿景
本项目旨在通过工程化手段，将传统基本面投资中的“手动搜集”与“直觉决策”转化为**可编程、可验证、可重复**的自动化流水线。

## 🏗️ 系统架构
项目的核心逻辑遵循“数据驱动决策”的漏斗模型：

1. **宏观与行业监测 (Sentinel)**: 追踪流动性、利率、行业估值水位线，基于大模型生成每日宏观简报。
2. **标准化投研逻辑 (Analyzer)**: 统一个股财务指标评价系,生成value line风格的一页投研报告。
3. **策略构建与回测 (Strategy & Backtest)**: 将投资哲学转化为因子，通过历史数据验证逻辑。

## 🛠️ 功能模块

### 1. 宏观/行业监测
* **宏观因子**: 10Y国债收益率、M2-M1剪刀差、采购经理指数（PMI）,基于大模型生成每日宏观简报。
* **行业脉搏**: 自动跟踪消费、医药、科技等行业 ETF 的 PE/PB 历史分位点，基于大模型生成行业观测报告。

### 2. 标准化投研
* **财务三表自动化**: 自动清洗标准化资产负债表、利润表及现金流量表。
* **核心指标评分**: ROE 稳定性、毛利率趋势、自由现金流覆盖率。
* **投研报告生成**: 生成value line一页式投研报告。

### 3. 策略与回测
* **因子化建模**: 将基本面逻辑（如：低估值 + 业绩反转）封装为可执行策略。
* **绩效评估**: 自动计算夏普比率、最大回撤等指标。
