# fundamental_quant_framework
一套集成宏观/行业监测、个股标准化投研与策略回测的深度投研框架，旨在构建系统化的基本面投资体系。

🎯 项目愿景
本项目旨在通过工程化手段，将传统基本面投资中的“手动搜集”与“直觉决策”转化为可编程、可验证、可重复的自动化流水线。

🏗️ 系统架构
项目的核心逻辑遵循“数据驱动决策”的漏斗模型：

宏观与行业监测 (Sentinel): 追踪流动性、利率、行业估值水位线。

标准化投研逻辑 (Analyzer): 统一个股财务指标评价体系，消除人工计算偏差。

策略构建与回测 (Strategy & Backtest): 将投资哲学转化为因子，通过历史数据验证逻辑有效性。

🛠️ 功能模块
1. 宏观/行业监测 (Market Monitoring)
宏观因子: 10Y国债收益率、M2-GDP剪刀差、股权风险溢价 (ERP)。

行业脉搏: 自动跟踪消费、医药、科技等行业 ETF 的 PE/PB 历史分位点。

景气度预警: 基于边际变化（同比/环比）的自动信号捕捉。

2. 标准化投研 (Standardized Research)
财务三表自动化: 自动清洗标准化资产负债表、利润表及现金流量表。

核心指标评分: ROE 稳定性、毛利率趋势、自由现金流覆盖率。

文本挖掘: 集成 LLM 对研报和公告进行关键信息提取（规划中）。

3. 策略与回测 (Backtesting)
因子化建模: 将基本面逻辑（如：低估值 + 业绩反转）封装为可执行策略。

绩效评估: 自动计算夏普比率、最大回撤、盈亏比等量化指标。
